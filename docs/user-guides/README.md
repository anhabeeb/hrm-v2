# OmniCore - HR User Guides

This folder contains the Phase 15 user-facing and admin-facing documentation set for OmniCore - HR.

Use these guides in this order for a new installation:

1. Admin Configuration Guide
2. Module Settings Guide
3. Security and Permissions Guide
4. HR Operations Guide
5. Onboarding and Offboarding Guide
6. Document Compliance Guide
7. Payroll and Payment Guide
8. Attendance, Leave, and Roster Guide
9. Reports, Import, and Export Guide
10. Background Jobs and Performance Guide
11. Production Operations Runbook
12. Troubleshooting Guide

The guides use safe sample values only. They do not include secrets, real employee data, real bank data, or destructive production SQL.
