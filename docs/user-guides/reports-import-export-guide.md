# Reports, Import, and Export Guide

## Reports

Reports cover HR, payroll, finance, attendance, leave, roster, document compliance, contracts, assets/uniforms, audit, onboarding, and offboarding where enabled.

## Report Preview and Exports

Report preview uses scoped filters. Large report/export work can queue background jobs. Export artifacts become ready for download and may expire according to retention settings.

## Import Validation

Use templates, upload, validation preview, row-level errors, pagination, and apply job. Fix validation errors before applying. Retry failed jobs only after reviewing the cause.

## Permissions and Disabled Modules

Report, import, and export lists are filtered by permission and disabled-module state. Sensitive exports require permission, reason, and audit where configured.
