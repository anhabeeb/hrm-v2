# Attendance, Leave, and Roster Guide

## Attendance

Attendance records show source logs, daily summaries, missing punch, late, early leave, correction status, payroll impact, and payroll lock behavior.

## Attendance Corrections

Employees or managers can request corrections where enabled. Corrections store current and requested values and require review when configured.

## Attendance Lock Day and Disable Effective Date

Monthly attendance lock day protects payroll periods. Attendance disable effective date behavior should be reviewed before saving.

## Leave

Leave requests use policy-aware calculation, balance cycles, ledger entries, document requirements, payroll impact, and approval chain/timeline preview.

## Roster

Roster planning defines expected work, shift templates, weekly assignments, published snapshots, changed-after-publish status, and roster-aware leave day context.

## Module Interaction

Attendance disabled does not disable Leave, Roster, or Payroll. Roster can run without Attendance. Payroll can run without Attendance and must not use Attendance data when Attendance is disabled.
